# 架构说明

> 这份文档说明这个站点是怎么搭的：两套渲染器共用一个内容模型、相机与网格的参数、AI 向导的工作方式、以及部署链路。
>
> 内容怎么写、加在哪里，见 [CONTENT.md](CONTENT.md) 与 [CONTENT-SLOTS.md](CONTENT-SLOTS.md)。

---

## 1. 一句话

一份结构化内容，渲染成两个完全不同的东西：**一份可被爬虫与屏幕阅读器读取的语义 DOM**，和**一块可自由缩放平移的 WebGL 画布**。两者读同一个 `Slide[]`，永远不会说不一样的话。

```
src/data/content.ts
        ↓  slides.ts（生成器）
    Slide[]（36 张）
        ├──→ SemanticDeck   语义 HTML —— SEO / 无 JS / 屏幕阅读器
        └──→ Canvas         PixiJS —— 平移缩放、飞行动画、标注工具
```

**为什么是两套而不是一套**：画布上的字是 WebGL 里的像素，爬虫读不到、屏幕阅读器念不出、Ctrl+F 搜不着。所以语义 DOM 不是降级方案，是同等公民——它在导出的 HTML 里就是完整内容，画布启动后才把它视觉隐藏（保留在无障碍树里）。JS 挂掉，站点自动退回成一个朴素但完整的网页。

## 2. 技术栈

| 层 | 选型 |
|---|---|
| 框架 | Next.js 16（Turbopack），`output: "export"` 静态导出 |
| 画布 | PixiJS v8（WebGL2） |
| 样式 | Tailwind v4 |
| 托管 | Azure Storage 静态网站 |
| 后端 | Azure Functions（Consumption），Node 24 |
| 存储 | Azure Table Storage |
| 语音 | OpenAI Realtime，WebRTC 直连，密钥不下发浏览器 |
| CI | GitHub Actions |

`trailingSlash: true` 是必须的：Azure Storage 静态网站**没有 rewrite 规则**，只按精确路径取 blob。不加的话 `/explore` 是 404，只有 `/explore.html` 能开——而那不是 canonical 标签、sitemap 和分享链接里的地址。

## 3. 内容模型

见 [CONTENT.md](CONTENT.md)。这里只说与渲染相关的三点：

**幻灯是生成的，不是手写的。** 一个项目条目自动产出 1 + ⌈bullets/2⌉ 张幻灯，索引页、菜单、锚点、搜索索引全部随之更新。没有任何一张幻灯是手工排版的。

**布局用一个字符串编码。** `layoutId` 把「基础布局 + 主题 + 媒体槽位」编成 `project-cover-right-dark` 这样的 id，两套渲染器各自解析。加一种布局不需要改数据结构。

**双语是数据的一部分，不是后处理。** 散文字段是 `{ en, zh }`，专名与技术名是裸字符串。`t()` 在渲染时解析，两套渲染器共用。

## 4. 世界几何与相机

### 4.1 网格

幻灯 1000×600，列间距 1100、行间距 700，9 列一行。

**行主序**：从左到右，到行尾换到下一行开头。就是正常的阅读顺序。

```ts
function gridCell(index) {
  return { row: Math.floor(index / COLS), col: index % COLS };
}
```

方向键在行尾**按阅读顺序环绕**：行尾按右 → 下一行第一张，行首按左 → 上一行最后一张。不环绕的话，访客一直在按的那个键会突然失效，而牌堆还在继续——跨行的项目看起来就像在那儿断了。

> ⚠️ **曾经的做法：蛇形排布**（偶数行从左往右，奇数行从右往左）。动机是让相邻幻灯的距离恒为 1100 或 700px，避免行尾那次 8800px 的横跨。代价更大：每隔一行就是倒着读的，没人会这样预期一个网格；方向键也跟着颠倒——在从右往左的行上，推进牌堆的键是**左**键，于是在那一行的最右列按右键**是往回走的**。
>
> 行尾那次长距离飞行是保留下来的代价，但它是**看得懂**的——就是一次回车换行。

### 4.2 相机参数

```
缩放范围        0.1 – 5×          滚轮灵敏度 0.01
惯性衰减        0.72              低于 0.5 停止
滚轮速度增益    0.3，衰减 0.8
触摸速度增益    6.4，平滑 0.6，抬手甩动加成 1.8
俯冲阈值        缩放 < 0.8 时双击才俯冲
LOD             缩放 < 0.3 只画卡片，不画正文
开场            总览停留 900ms，俯冲 2600ms
```

LOD 那条是性能的关键：36 张卡的正文是数千个绘制调用，总览时全画会掉帧。

### 4.3 飞行动画

时长随距离自适应，1600–2600ms，`easeInOutCubic` 配一个 `sin(p·π)` 的拱形缩放包络——先拉远、再推近，像镜头抬起又落下。

**关键实现细节：插值的是焦点，不是容器偏移。**

```ts
// 每一帧：先算出此刻的焦点与缩放，再由它们导出容器位置
const focus = lerp(fromFocus, toFocus, easeInOutCubic(p));
const scale = lerp(fromScale, toScale, ...) * archEnvelope(p);
world.position = cameraFor(screenW, screenH, focus.x, focus.y, scale);
```

直接对容器 x/y 做插值、同时让缩放走拱形，会导致焦点**超冲目标 113% 再弹回来**——观感是「一路往右滑，然后突然高速蹿到位」。焦点插值下实测超冲 0.0%，全程单调。

## 5. 路由：`slide://` 作为唯一枢纽

菜单点击、键盘、幻灯上的链接、AI 向导的跳转——**全部走同一条命令**。按前缀分派：

```
slide://<id>   画布内导航
#<anchor>      画布内导航
<数字>          按索引跳转
mailto:…       location.href
其他            新标签页打开
```

AI 向导因此**没有任何进入画布的特权通道**——它发出的就是菜单点击发出的那条命令。

组件之间用事件总线（`canvas/bus.ts`）通信：React 的外壳和 PixiJS 的世界互不持有引用，命令往下、状态往上，任意一侧都能被替换。

## 6. 主题：白色栅格化 + tint

所有画布元素**一律以白色栅格化**，颜色由 `tint` 在 GPU 端施加。切换主题时遍历场景树重新赋 tint。

```ts
function paint(node, role, palette) {
  node.__role = role;          // 记住语义角色
  node.tint = palette[role];   // 施加当前配色
  return node;
}
```

把颜色烤进 `TextStyle` 的话，切主题要重建全部 36 张幻灯——实测 1 秒，中间还得盖个加载动画。tint 方案实测 **0.2 毫秒**，无感切换。

标注（高亮、emoji、便利贴）**不带 role**，所以 `repaint` 会跳过它们——便利贴在暗色主题下仍是便利贴，不会变成灰纸片。

### 6.1 语言：懒重建

主题能用 tint 瞬时切换，语言不能——**字变了，长度就变了，版面必须重排**。

但也不能整个重建：拆掉 effect 重建画布会带回加载动画，还会把镜头丢回开场，那正是主题切换当初修掉的体验。

所以是**懒重建**：

```
切换语言 → 全部 36 张标记为过期
         → 立刻重建屏幕上的那几张（缩放时约 7 张）
         → 其余的在 cull() 发现它们进入视野时才重建
```

`cull()` 在每次镜头移动时都会跑——平移、滚轮、触摸、飞行的每一帧、惯性滑行。所以一张幻灯**不可能以旧语言出现在屏幕上**。

> 顺带修了一个先前就有的 bug：`resizeTo` 只调整画布尺寸，**没有任何东西在窗口缩放后重新剔除**。把窗口拉大，本该进入视野的幻灯会一直隐藏到下一次镜头移动。

语言与主题共用 `site-locale` / `explore-theme` 两个键，**`site-locale` 与经典首页是同一个**——在 `/` 切了中文，进 `/explore` 不该回到英文。

## 7. 画布工具

工具坞在底部居中，工具的选项**在坞内就地展开**而不是浮层——浮层正好会盖住访客马上要标注的那块画布。

| 工具 | 实现 |
|---|---|
| 高亮 | `Graphics` 逐段描边，`alpha 0.38 / width 18 / round cap`。这个组合才读作「马克笔覆盖」而非「划线穿过」 |
| emoji | `PixiText`，单击即落 |
| 便利贴 | 点击落钉 → **DOM `<textarea>`** 浮在点击点 → 回车提交 → 画进标注层 |

**便利贴的文字输入必须留在 DOM**：PixiJS 没有文本输入，自绘会破坏 IME 组合输入，等于把中文用户挡在门外。

标注放在 `world` 容器内（世界坐标），所以标记**粘在幻灯上**，镜头一动跟着动。

**鼠标与触摸是两套独立代码路径**（捏合、甩动、惯性没有鼠标对应物），所以工具手势抽成 `toolDown/toolMove/toolUp` 三个共用函数——只写在 `onPointerDown` 里的话，手机上会完全静默失效。双指恒为捏合缩放，无论是否持有工具。

## 8. 便利贴后端

`/api/notes` 是**全站唯一接受匿名写入的端点**，所以每条限制都是为防滥用而不是扛负载：

| 层 | 措施 |
|---|---|
| 来源 | origin 白名单，非白名单 403 |
| 开关 | `NOTES_ENABLED` 不为 `true` 时整个端点 503 |
| 限流 | 每 IP 每分钟 6 条 |
| 长度 | 280 字符截断 |
| 颜色 | 必须是画布真的提供的那五个之一 |
| 作者 | **只存加盐哈希**，没配盐就一个字不存——无盐的 IP 哈希是可逆的 |

存储在静态站已有的那个存储账号的 Table 里，不新开资源：

- `partitionKey` = `YYYY-MM`（按月分区，列出时不必全表扫描）
- `rowKey` = `(9999999999999 - 时间戳)-<8位随机>`（Table Storage 按 rowKey 升序，倒数即最新在前）

读取用 `GET` 带管理密钥返回 JSON。两个刻意设计：**没配密钥 = 读取关闭而不是开放**（漏配的环境变量绝不能成为公开全部留言的原因）；**错密钥答 404 而不是 403**（不向探测者确认端点存在）。

## 9. AI 向导

浏览器**不持有任何密钥**。它把 SDP offer 发给 Azure Function，函数用真钥换一个短期 secret 并代为交换 SDP，只把 answer 送回。之后音频在浏览器与服务商之间直连，函数不在音频链路上。

### 9.1 接通即开讲

接通后向导**自动开始一段固定路线的导览**，走 8 个顶层章节，边讲边飞镜头。

刚授权麦克风那一秒是访客唯一必然在场的注意力，用来问「你想看什么」多半换来沉默。

### 9.2 排序权在客户端

**导览由客户端一站一轮驱动**，不是把整条路线交给模型：

```
navigate(第 N 站)      ← 客户端跳转，不指望模型调工具
speak(只讲这一站)
  ↓ 生成完毕 且 音频缓冲放空
前进 → 900ms 间隔 → 第 N+1 站
```

三个必要条件，缺一不可：

1. **客户端跳转。** 路线是导览的全部意义；模型漏调一次工具就无声跳过一页。导览进行中，模型自发的跳转请求被确认但不执行。
2. **每站指令都禁止收尾**（`Do NOT greet / offer help / say anything that sounds like an ending`）。不写这条，模型每站都签收，读起来像导览反复结束。
3. **`awaiting` 守卫。** 一轮可能产生多个 `response.done`（工具调用自带一个），不守就会跳站。

### 9.3 ⚠️ 「讲完了」是两个事件的合取

`response.done` 是**生成完毕**，不是讲完。WebRTC 下音频作为媒体轨实时播放，而生成远快于播放——一段 15 秒的话约 2 秒就生成完，剩下 13 秒还在放。按它推进，幻灯会在访客还在听上一站时就跳走。

真正的播放完成信号是 **`output_audio_buffer.stopped`**：出站音频缓冲放空。它不在通用事件文档里，因为它**只在 WebRTC 和 SIP 下发送**，这是它当初被漏掉的原因。

一轮结束 = `response.done` **且** `output_audio_buffer.stopped`。两个缺一不可：

- 只看 `response.done` → 早跳 13 秒
- 只看 `output_audio_buffer.stopped` → 缓冲若在轮次中途短暂放空会误判。而**播放不可能比生成先结束**，所以生成未完时的放空一律丢弃

顺带修掉一个与时序无关的跳站：只调工具的一轮自带一个 `response.done`，旧规则下它会结束当前站。它不开音频缓冲，现在什么都不结束。

> ⚠️ **曾经的错误做法**：`AnalyserNode` 每 80ms 采样 RMS，静音满 700ms 就前进。音量分不清「两句话之间的换气」和「讲完了」——说话人换口气就结束一站，镜头跳走而上一站的音频还在放。这正是「没讲完就跳页」和「讲的和页面对不上」两个症状的同一个成因。
>
> 该路径保留为兜底（阈值放宽到 1500ms），只在服务商不发 `output_audio_buffer.*` 时才走。

### 9.4 ⚠️ `response.instructions` 是替换，不是追加

`response.create` 带 `instructions` 会**替换该轮的会话级 instructions**。会话 instructions 里装的是「人设 + 全部 36 张幻灯正文」，所以导览每一轮都会把它整个丢掉。

代价踩过两次：

- 丢掉人设 → 向导开始**对着 Evan 本人说话**（「这一页讲的是**你**的背景」），而不是把 Evan 介绍给访客
- 丢掉目录 → 向导**不知道页面上写了什么**，只能空谈「这是个介绍，篇幅较短，宜作开场脉络」

所以每站指令必须**自带身份框架 + 该站正文**。这不是冗余，是它们唯一能待的地方。

### 9.5 ⚠️ 语音活动检测不等于「访客开口了」

`input_audio_buffer.speech_started` 会因为外放时听到向导自己的声音、或一声咳嗽而触发。按它放弃导览，等于**一次误触发杀死整场导览**——实测停在一个空白章节页再不动，而向导还在讲。

分开处理：

| 事件 | 动作 |
|---|---|
| `speech_started` | **暂停**，保住位置 |
| 转录完成且有文字 | 结束导览 |
| 转录为空 / 转录失败 / 3.5s 无下文 | **恢复** |
| 点麦克风按钮 | 结束（明确意图，不含糊） |

### 9.6 内容决定上限

向导被硬性禁止说幻灯上没有的事实。**内容写得具体，它讲得具体；写得笼统，它只能笼统。** 这是刻意设计。

## 10. SEO

静态导出 + 语义 DOM 意味着爬虫拿到的就是完整内容。

- `robots.ts` / `sitemap.ts` / `opengraph-image.tsx` 全部由内容源派生
- sitemap 列的是**锚点** URL（`/explore#tencent`），因为一个页面后面挂着 36 张幻灯
- `/explore` 需要**自己的** `opengraph-image.tsx`：路由里定义 `openGraph` 会**替换**父级的而不是合并，静默丢掉分享图

## 11. 部署

静态站走 GitHub Actions：构建 → 类型检查 → 39 项单元测试 → 导出校验 → 上传 → **设置缓存头** → 修分享图 content-type → 清理陈旧 chunk → 线上冒烟测试。

### 11.1 缓存头是必须显式设置的

Azure Storage 上传的 blob **不带任何 `Cache-Control`**，浏览器于是走启发式缓存，可以不回源就发旧 HTML——而旧 HTML 指向的 chunk 文件名已经被清理步骤删了。

```
_next/static/*   public, max-age=31536000, immutable   （哈希名，同名内容永不变）
*.html           no-cache                              （每次回源校验）
```

冒烟测试里有断言：HTML 少了 `no-cache` 就让部署失败。

> `az storage blob update-batch` 这个命令**不存在**，只有 `upload-batch`。所以缓存头是在上传时带上的。

### 11.2 ⚠️ 函数应用打包不能用 `Compress-Archive`

Windows PowerShell 5.1 的 `Compress-Archive` 用**反斜杠**写压缩包内的条目名。函数宿主跑 Linux，会把 `node_modules\@azure\functions\...` 整个当成一个文件名而不是目录路径，于是 `node_modules` 永远解析不到，**一个函数都注册不上**——整个应用 404。

用 Python `zipfile`（永远写正斜杠），并在打包后断言压缩包里不含反斜杠。

## 12. 踩过的坑（按类别）

### 12.1 浏览器行为

| 现象 | 原因 |
|---|---|
| 后台标签页里飞行动画、俯冲、搜索聚焦全部失效 | rAF 在不绘制的标签页里被挂起。改用 `setTimeout` 或直接调用 |
| CSS 过渡「卡在中间不动」 | 同上，页面不合成画面时过渡被节流。**量任何带过渡的东西前，先把过渡时长强制为 0** |
| 工具坞塌成 17px（正好是滚动条宽度） | `calc(100vw-2rem)` 是**无效 CSS**——减号两侧必须有空格。Tailwind 任意值里空格要写成下划线。已全部改为行内 style |

### 12.2 渲染

| 现象 | 原因 |
|---|---|
| 语义 DOM 盖在画布上、卡片黑底黑字 | `elementFromPoint` 返回 `A` 而不是 `CANVAS`。用 `data-canvas` 标记 + CSS 裁剪解决 |
| 打开网页先闪几秒原始 HTML | 加同步 boot 脚本 + 加载动画 + 8 秒看门狗 |
| `Application.destroy` 被调用两次 | 分块构建里销毁了 cleanup 也持有的实例。StrictMode 下每次必现。构建里只允许 bail out，不许销毁 |

### 12.3 平台

| 现象 | 原因 |
|---|---|
| CORS 预检没有任何响应头 | 两个叠加原因：运行时在 204 上丢弃响应头（改用 200 + 空 body），且平台在 handler 之前拦截 OPTIONS（需在函数应用上配置平台 CORS） |
| 本地开发 `Failed to fetch` | 来源白名单只有线上域名。CORS 失败时浏览器**故意不说原因**，只给一个 `TypeError`。平台 CORS 与 `ALLOWED_ORIGINS` 两处都要加 localhost |
| 分享图变成 octet-stream | Next 输出的分享图**没有扩展名**，Storage 按扩展名推断类型。上传后需单独重设 content-type |

### 12.4 CI

| 现象 | 原因 |
|---|---|
| `Cannot find name 'LayoutProps'` | Next 16 在构建过程中生成路由类型，`tsc` 跑在构建之前就找不到。必须先 build 再 typecheck |

